# Важный Гусь

Почтовый клиент для Windows: Яндекс, Mail.ru, Gmail и любая почта на своём домене.

## Скачать

**[Последняя версия →](https://github.com/s-brb/vazhny-gus-releases/releases/latest)** — там нажмите на файл `VazhnyGus_…_x64-setup.exe`. Регистрироваться на GitHub не нужно.

## Установить

1. Запустите скачанный файл.
2. Если Windows покажет синее окно «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с программами без платной цифровой подписи.
3. Установка не требует прав администратора. Программа появится в меню «Пуск».
4. При первом запуске подключите свою почту. Для Яндекса, Mail.ru и Gmail нужен пароль приложения (ссылка на его страницу — прямо в окне подключения), для почты на своём домене — обычный пароль от ящика. Пароль хранится только на вашем компьютере, в защищённом хранилище Windows.

## Обновления

Программа сама проверяет, не вышла ли новая версия, и предлагает обновиться в один щелчок. Почта и настройки при обновлении сохраняются. Проверить вручную: «Настройки» → «О программе» → «Проверить обновления».
